**NOTE!!! KONDISI INFRASTRUCTURE DISINI SAMA SEPERTI DI CASE STUDIES BACA TERLEBIH DAHULU CASE STUDIES,[DISINI](https://rizkiyusupk.github.io/case-studies/scale-nodes/)**
Masuk ke bagian config karena kondisi infrastrcuture sudah ada dan harus ada 6 node atau domain dan 2 cluster sesuai dengan kondisi terakhir di case studies,jadi untuk infrastructurenya
saya akan menggunakan infrastrcuture yang sama ingat hanya infrastrcuturenya saja jadi hanya membuat nodenya saja saya ulangi sekali lagi hanya pembuatan nodenya saja jadi sekarang harus
ada 6 node dan 2 cluster,oke masuk ke config pertama yaitu installasi untuk argocd itu sendiri masuk ke playbook pertama yaitu untuk installasi argocd

```
vim argocd.yaml
|
- name: install argocd
  hosts: masters,masters-cluster-2
  become: yes
  become_user: ubuntu

  tasks:
    - name: create namespace
      ansible.builtin.shell: kubectl create namespace argocd
    - name: install argo
      ansible.builtin.shell: kubectl apply -n argocd --server-side --force-conflicts -f https://raw.githubusercontent.com/argoproj/argo-cd/stable/manifests/install.yaml
```

ada yang berbeda dengan playbook biasanya di playbook argocd ini biasanya menggunakan root user kali ini saya menggunakan user ubuntu,kenapa? karena didalam tasks argocd akan ada
penggunaan dari command kubectl sedangkan kubeconfig ada di user ubuntu,jika saja menggunaakn user root akan terjadi error api,karena kubeoconfig di ubuntu system akan bingung 
jika sudah gunakan command


```
ansible-playbook playbook.yaml
|
ansible-playbook argocd.yaml
```

tunggu hingga proses selesai jika sudah cek menggunakan command 

```

```

karena semua pods argocd akan berjalan otomatis didalm namespace argocd ketika berhasil diinstall
